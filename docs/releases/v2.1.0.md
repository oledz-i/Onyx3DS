**ONYX v2.1.0: the speed update.**

The software renderer was rebuilt around the Xbox's CPU cores, frame skip keeps slow scenes playable, the home menu has a new look and sound, and the hardware renderer got its biggest round of fixes yet.

> **ONYX is in ALPHA.** It is in its infancy and can't be expected to work flawlessly yet. Some games run slowly or not at all.

> **A patch update (v2.1.1) will likely follow soon after v2.1.0.** If something breaks, please report it in the [Issues](https://github.com/oledz-i/Onyx3DS/issues) tab and attach your `onyx.log`.

### Install
Download **two files** below: `ONYX3DS-v2.1.0.msix` and the dependency `.appx`. In the Xbox Device Portal choose **Add**, pick the `.msix`, add the dependency, and install. Keep ONYX's **App type set to Game** in Dev Home. Full guide: [docs/INSTALL.md](https://github.com/oledz-i/Onyx3DS/blob/main/docs/INSTALL.md).

### What's new
- **Much faster software rendering.**
  - Each draw call is split into screen bands that every available core draws at once, with the emulation thread helping. Before, most triangles were drawn one at a time on a single thread.
  - The number of drawing threads matches the cores the Xbox actually gives the app.
  - Screen transfers and the final screen conversion run on all cores.
  - Per-pixel work is cheaper:
    - The texture combiner (about a quarter of the emulation thread's time) is decoded once per triangle instead of for every pixel.
    - Unused texture coordinates and pass-through color stages are skipped.
    - Each triangle row's covered span is computed directly.
    - Same-format screen copies are plain memory copies.
  - Textures are decoded once and reused, instead of being decoded again for every pixel drawn.
  - In testing on a Series S, the New Super Mario Bros. 2 menus went from about 2 fps (v2.0.1) to full speed with frame skip, gameplay runs at about 20–28 fps, and Shakedown Hawaii holds 60 fps.
- **Automatic frame skip (on by default).** While emulation runs behind real time, ONYX skips drawing a frame (never more than 3 in a row) so the game itself keeps full speed. Set it to Off, or to a fixed 1–3, in Settings, the in-game menu, or per game. Some games may flicker.
- **Smoother pacing and audio.** A frame limiter stops games from running past 60 fps, and audio is time-stretched while a game runs slow, so it no longer crackles or stutters as much.
- **Hardware renderer fixes** (still experimental, see below):
  - Fixed the leading suspect for the Series S crash: an image view in a format the Xbox can't convert, which removes the whole GPU device. Dozen now writes a safe empty view there instead.
  - Shaders that the Xbox's shader validator refuses are signed by ONYX, so the driver can compile them. Integer textures are now read with texel fetches, which Direct3D requires.
  - Descriptor heaps stay within what the Xbox allows.
  - If anything else removes the GPU device, `onyx.log` now names the exact call and the 15 before it.
- **New home menu look and sound.**
  - New rounded menu font (Rounded M+ 1c), in the spirit of the classic console menus.
  - New optional **Dual Screen** theme in the style of the 3DS home menu: Settings > Theme.
  - New menu music. *Plaza* (Aero Channel) is a calm, bouncy piano tune in the spirit of the Wii menu. *Afterglow* (Midnight Onyx) is an ambient, PS4-style dashboard piece. Dual Screen has its own handheld-style tune.
- **Quality of life.**
  - If the emulator crashes, **Restart ONYX** restarts the app and reopens your game. Before, you had to close and reopen ONYX yourself. The error message is now in plain words, with the technical details at the end.
  - Themes can name their own bold font (`font_bold` in `theme.json`).
- **Fixes.**
  - A Vulkan error while setting up the hardware renderer could make the emulator spin a CPU core at 100%. It now stops with an error instead.
  - `onyx.log` records where each screen is drawn whenever the layout changes. This will help find the thin bar some people see above the picture.

### Known issues
- The **hardware renderer** is still experimental on Series S. If it fails, ONYX switches back to software automatically. Please attach `onyx.log` to an issue: the driver lines show exactly what failed. If it does run, shadows in some games may be missing.
- Heavy 3D games are still slow on the software renderer. Frame skip and a lower CPU clock can help.
- Some people see a thin colored bar above the game picture. If you see it, please say in your issue which screen layout you use.

`ONYX3DS-v2.1.0.map` is only for decoding logs; you don't need it to install.
