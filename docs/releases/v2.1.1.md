**ONYX v2.1.1: hardware renderer fix and more speed.**

> **ONYX is in ALPHA.** It is in its infancy and can't be expected to work flawlessly yet. Please report problems in the [Issues](https://github.com/oledz-i/Onyx3DS/issues) tab with your `onyx.log`.

### Install
Download `ONYX3DS-v2.1.1.msix` and the dependency `.appx` below and install them from the Xbox Device Portal (Development drive). Keep ONYX's **App type set to Game** in Dev Home. Full guide: [docs/INSTALL.md](https://github.com/oledz-i/Onyx3DS/blob/main/docs/INSTALL.md).

### What's new
- **Hardware renderer: found why every GPU command batch failed.** The error `vk::CommandBuffer::end: ErrorOutOfHostMemory`, seen since the hardware renderer first ran, came from a call Dozen made for every draw: setting a "view instance mask", which the Series S GPU doesn't support. Xbox rejects the whole batch of commands for it. Dozen now only makes that call on GPUs that support it.
- **The hardware renderer now runs games.** In testing, New Super Mario Bros. 2 ran at 60 fps on the hardware renderer, with sound.
  - **Fixed the black picture.** ONYX draws the 3DS screens onto the frame with "constant alpha" blending. The Series S GPU (without the newer Direct3D feature for it) was handed the wrong blend factor, so every screen was blended in at 0% and only the black background was left. Dozen now gives the GPU the right factor.
  - **Fixed the crash after about a minute** in some games: 16-bit depth buffers were created in a way the Xbox rejects. They're now created in a form it accepts.
  - **Fixed the stutter every couple of seconds** (and the crackly audio that came with it): each time the CPU recompiler wrote new code, it switched write protection on and off for its whole 16 MB+ code area. It now only unlocks the pages it's writing to.
  - **Smoother picture:** frames are handed to the screen in step with the TV's refresh, instead of on a timer that drifted against it and repeated or skipped a frame every half second. The unused display layer underneath no longer redraws blank frames.
  - Textures the emulator throws away are now freed on a background thread, and the GPU descriptor pools are 4x bigger, so neither interrupts a frame anymore.
  - **Fixed a crash** when the Xbox GPU driver rejects one version of a graphics pipeline: the draw is skipped instead of crashing.
  - **Fewer freezes when something new appears on screen.** The Xbox GPU driver takes about half a second to build each new graphics pipeline, and Dozen did that in the middle of drawing a frame, so the game froze each time. They're now built on background threads before the game needs them.
  - **Less stutter in general:** small GPU upload buffers, and the GPU buffers Dozen uses to draw triangle fans and to copy textures between formats, are reused instead of created and freed every frame (each one was a trip into the Xbox kernel). A debug check that ran on every GPU call now runs rarely.
  - **No geometry shaders on Xbox.** Lit 3D scenes used an extra GPU stage that is slow on the Series S, took up to a second to build, and is the likeliest reason the Xbox driver refused some of their pipelines (the objects drawn with them disappeared). Lighting is now interpolated without it.
  - **Fixed a crash** in games that draw with an oversized vertex range: the emulator read past the end of the 3DS memory it was copying from. It also logged an error on every such draw, thousands per second, which slowed those scenes down.
  - Shaders compile in the background, and after the first few they skip a validation pass that only produced log lines.
  - Each frame's GPU work is now submitted before ONYX copies the picture, so the frame it shows is finished.
  - Hardware frames reach the screen with one less full-frame copy.
  - A game creating an empty texture no longer crashes the emulator.
  - The startup GPU check now also draws a test picture the way the emulator does, so `onyx.log` says right away whether drawing works.
- **Faster software rendering.**
  - Simple texture and texture-times-color drawing (most 2D and menu graphics) takes a direct shortcut through the texture combiner.
  - Frames skipped by frame skip no longer run the vertex shader.
- **New: Frame rate lock** (Settings > Emulation, or per game). *60 fps* is the default. *30 fps, steady* shows every second frame at an even pace while the game itself keeps running at full speed, so a heavy game feels smoother than when it jumps between 40 and 60.
- **Smoother logging:** warnings no longer force a disk write each time (bursts of them caused hitches), and the driver log is checked without reopening the file every two seconds.
- **Shaders are built once per game, not after every update:** with a USB drive set up, the shader caches live in its System folder, so reinstalling ONYX no longer throws them away. The second time you play a game, its effects are ready from the start.
- **FPS overlay shows the worst frame time** of the last half second next to the FPS, so stutter is visible even when the average says 60.
- **Custom textures only load when the game has a texture pack installed.** Before, every texture was hashed and looked up in a pack that wasn't there.
- **Livelier home menu:** the ONYX mark and a greeting in the header, the selected game's name and play time on the right, Xbox-coloured button hints along the bottom, tiles that fade in one after another, and slow floating lights in the background (off when background motion is off).
- **Redesigned Settings:** a header with your console, renderer and build, sections with icons and one-line descriptions, a large title card for each section, the setting under the cursor highlighted, and LB / RB to jump between sections.
- **A nicer startup screen**: a soft glow behind the ONYX mark and a cleaner wordmark, at full sharpness on 4K. It's a still image, so startup is just as fast.
- **Settings > About shows the build stamp**, the same one at the top of `onyx.log`, so you can see which build is installed.
- Credits now list the Rounded M+ 1c font.

### Known issues
- The hardware renderer is still experimental. If it fails, ONYX shows what happened and switches back to software. Please attach `onyx.log` to an issue.
- Shadows may be missing in some games on the hardware renderer.
- **On the hardware renderer, the game still freezes for about half a second every second or two.** The emulator is waiting for the GPU to finish a frame, and the GPU really is finishing late. ONYX now times every batch of GPU work, records how often its vertex and uniform buffers wrap around, and sums up every GPU memory call every 5 seconds, so `onyx.log` shows what the GPU is doing during the freeze. Please send that log.
