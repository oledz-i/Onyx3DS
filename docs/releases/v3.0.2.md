**ONYX v3.0.2: keyboard fix.**

A quick patch for the on-screen keyboard in v3.0.1.

- Controller buttons were being read as the wrong keys, so the on-screen keyboard's controls did not do what the hints said. Buttons are now read by their real identity.
- Stray spaces were being typed when you used the controller. Only a real USB/Bluetooth keyboard can type characters now; the controller types through the on-screen keys.

Nothing else changed from v3.0.1. Install over your existing copy.
