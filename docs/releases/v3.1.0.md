**ONYX v3.1.0: a persistent vertex cache for big speed gains in geometry-heavy games, ONYX's own OpenGL (experimental), Zelda and Mario Kart 7 graphics fixes, and a lighter default.**

What's new
- **Game Boy Advance.** GBA is now a system, running on the mGBA core. It has its own Library tab and Roms/GBA folder, IPS/BPS/UPS patching for ROM hacks (from Patches/GBA, applied in memory), battery saves, and picture settings (colours, screen shape, upscaling look, ghosting blend, softer sound) in the quick menu and in Settings.
- **Crossbar home screen (XMB style).** Turn it on under Settings > Interface > "Crossbar home screen". Games are arranged in categories: Recent, Favourites and one per system. The D-pad, triggers and bumpers move between categories, and the quick menu now opens with an animation, a cover header and a focus zoom. It's optional and off by default.
- **Game details on the crossbar.** Hovering a game (Settings > Interface > "Game details on the crossbar") shows its banner and logo, play facts, and after a moment its description, release date, developer, publisher and genre, plus a slow screenshot slideshow behind the panel.
- **Better cover art.** The SteamGridDB picker lists the games it found (3DS-era releases ranked first) so you can choose the right one, or paste a picture link. Artwork now downloads four games at a time, remembers misses for a week and no longer hangs on a stalled download.
- **Persistent vertex cache (Vulkan and OpenGL).** 3D models are copied to the GPU once and kept there until the game changes them, instead of being copied again on every draw. Mario Kart 7 was moving about 10 GB of vertex data per second through the CPU; static track and character geometry is now uploaded once. Geometry the game keeps rewriting is detected and handled the old way.
- **ONYX's own OpenGL renderer (experimental).** It now offers OpenGL 4.3 on the console, which the emulator needs (before, it reported 4.1 and every game quietly fell back to Vulkan). Built from public Mesa sources and our own code, it runs on the console's DirectX 12 and is selectable under Settings > Renderer > "Hardware (OpenGL, experimental)". If it can't start, the game falls back to Vulkan and ONYX tells you on screen.
- **Graphics fixes (Vulkan).** Ocarina of Time 3D's logo and Link now draw correctly with hardware shaders on, Smash 4 and Tomodachi Life no longer lose draws to refused pipelines, the missing track texture in Mario Kart 7 is fixed, and shadows now render on the console. A "complete graphics" mode waits for pipelines instead of skipping draws, which removes holes in Zelda.
- **Safeguards against bad pictures (Vulkan).** New images now start cleared on the console's graphics driver, and the vertex cache double-checks that cached models still match the game's memory. These target coloured static and flashing black models or sky (seen in Smash 4 and Mario Kart 7). They are attempts: some of these glitches may remain, so please send a log if you see them.
- **Original 3DS is the default system model.** It uses less CPU and memory and suits almost every game; choose New 3DS per game (or in Settings) for the few that need it. Your saved default is switched once.
- **Clearer help for encrypted games.** Instead of an error, ONYX explains how to decrypt your own dump (for example with Batch 3DS Decryptor) or where to put your keys.
- **Performance.** Smoother frame hand-off for software-path frames, faster picture conversion on the CPU path, more upload buffers, and games start un-muted.

Things to know
- "Remember compiled graphics" stays experimental and off by default: in testing it crashed the graphics driver on console.
- OpenGL is new and has had little testing on real consoles. Known issue: the bottom screen can show black on OpenGL; use Vulkan if you need it. Please send logs if anything breaks.
- Mario Kart 7 can still flash black characters or sky in some races; this is being investigated.
- GBA and the crossbar are new and have had little testing on a console.

ALPHA software. Please send logs if anything breaks.
