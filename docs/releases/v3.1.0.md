**ONYX v3.1.0: a persistent vertex cache for big speed gains in geometry-heavy games, ONYX's own OpenGL (experimental), Zelda and Mario Kart 7 graphics fixes, and a lighter default.**

What's new
- **Persistent vertex cache (Vulkan and OpenGL).** 3D models are copied to the GPU once and kept there until the game changes them, instead of being copied again on every draw. Mario Kart 7 was moving about 10 GB of vertex data per second through the CPU; static track and character geometry is now uploaded once. Geometry the game keeps rewriting is detected and handled the old way.
- **ONYX's own OpenGL renderer (experimental).** It now offers OpenGL 4.3 on the console, which the emulator needs (before, it reported 4.1 and every game quietly fell back to Vulkan). Built from public Mesa sources and our own code, it runs on the console's DirectX 12 and is selectable under Settings > Renderer > "Hardware (OpenGL, experimental)". If it can't start, the game falls back to Vulkan.
- **Graphics fixes (Vulkan).** Ocarina of Time 3D's logo and Link now draw correctly with hardware shaders on, and the missing track texture in Mario Kart 7 is fixed. Shadows now render correctly.
- **Safeguards against bad pictures (Vulkan).** New images now start cleared on the console's graphics driver, and the vertex cache double-checks that cached models still match the game's memory. These target coloured static and flashing black models or sky (seen in Smash 4 and Mario Kart 7). They are attempts: some of these glitches may remain, so please send a log if you see them.
- **Original 3DS is the default system model.** It uses less CPU and memory and suits almost every game; choose New 3DS per game (or in Settings) for the few that need it. Your saved default is switched once.
- **Clearer help for encrypted games.** Instead of an error, ONYX explains how to decrypt your own dump (for example with Batch 3DS Decryptor) or where to put your keys.
- **Smoother frame hand-off** for software-path frames, and a hover slideshow of screenshots on game pages.

Things to know
- "Remember compiled graphics" stays experimental and off by default: in testing it crashed the graphics driver on console.
- OpenGL is new and has had little testing on real consoles. Known issue: the bottom screen can show black on OpenGL; use Vulkan if you need it. Please send logs if anything breaks.
- Mario Kart 7 can still flash black characters or sky in some races; this is being investigated.

ALPHA software. Please send logs if anything breaks.
