**ONYX v3.0.1: an on-screen keyboard, better NES, and no more half-drawn scenery on Vulkan.**

> **ONYX is in ALPHA.** It is in its infancy and can't be expected to work flawlessly yet. Please report problems in the [Issues](https://github.com/oledz-i/Onyx3DS/issues) tab and attach your `onyx.log`.

### Install
Download `ONYX3DS-v3.0.1.msix` and the dependency `.appx` below and install them from the Xbox Device Portal (Development drive). It installs **over v3.0.0** and keeps your saves. Keep ONYX's **App type set to Game** in Dev Home. Full guide: [docs/INSTALL.md](https://github.com/oledz-i/Onyx3DS/blob/main/docs/INSTALL.md).

### What's new
- **New: on-screen keyboard.** Games that ask you to type (Tomodachi Life names, Mii names, search boxes) now get a real keyboard that appears only when the game asks for text. Controller: D-pad or left stick to move, **A** types, **B** deletes, **X** space, **Y** Shift, **LB / RB** move the cursor, **LT / RT** switch between letters, symbols and accents, **Menu** confirms, **View** cancels. Number-only requests get a number pad. A USB keyboard works too. Hold **View** for 1.5 seconds to close it whatever the game wants.
- **NES, much improved.**
  - A natural default palette instead of the over-saturated one, plus a palette choice in Settings.
  - The picture is sized to a 4:3 TV by default (with 8:7 and 16:9 stretch options) and drawn with a sharp scaler, which removes the shimmering and soft look while scrolling. The screen edges where games scroll in garbage are hidden by default, and you can change how much is hidden.
  - Smoother pacing and a battery save written in the background.
  - **ROM patches:** put `.ips`, `.bps` or `.ups` patches next to the game or in `Patches/NES` on your USB drive and pick one on the game's page (widescreen hacks, translations). A patch that doesn't match the game is refused and the game starts unpatched.
- **Vulkan: no more empty or half-drawn frames in new areas.** While the Xbox GPU driver builds a new graphics pipeline, ONYX now keeps showing the last complete picture instead of a frame with missing scenery (the blue screens before the graphics appear). The game keeps running at full speed; once the pipelines are ready, the picture jumps to the current frame. Builds of new pipelines also use more background threads.
- **OpenGL fast mode** (Settings > Emulation, on by default): the OpenGL driver skips its error checks, which saves processor time on every draw. ONYX turns it off by itself if the hardware renderer ever crashes.

### Known issues
- Hardware (Vulkan): in a new area the picture can pause for a second or so while pipelines build. It is cached afterwards, so it is much shorter the next time.
- Shadows may be missing in some games on the hardware renderers.
- NES is still new; some NES art may be missing or wrong.
- If the hardware renderer fails, ONYX shows what happened and switches back to software. Please attach `onyx.log` to an issue.
