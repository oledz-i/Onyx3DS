**ONYX v3.0.0: on-screen keyboard, NES improvements, Vulkan rendering, and all work from DanP's Azahar has been removed, effective immediately.**

At the author's request, everything in ONYX that came from DanP's Azahar has been removed, including the bundled OpenGL runtime, the OpenGL fixes patch and the credits for them. Earlier v3 releases contained that work and have been taken down. This release replaces them.

What's new
- **On-screen keyboard.** Games that ask for text (names in Tomodachi Life and similar) now get a controller-friendly keyboard that appears only when the game needs typing. A USB or Bluetooth keyboard works too.
- **NES.** Fixes for the oversaturated colours, picture shape and pacing, plus support for IPS, BPS and UPS patches (widescreen and other patches) from a Patches button on the game page.
- **Vulkan.** The screen now holds the last picture while new graphics finish building, instead of flashing blue or half-drawn scenery. Menus should also be smoother.
- **Direct display** is the default, and **save backup** copies your saves to the USB drive after each game.
- **Updates install over the old build**, keeping your saves and settings.

Things to know
- **OpenGL is gone for now.** Hardware rendering is Vulkan only until ONYX has its own OpenGL support. Anyone who had OpenGL selected is moved to Vulkan automatically. Software rendering is unchanged.
- If you installed v3.0.1 or v3.0.2 before they were taken down, Windows will not install this over them. Uninstall ONYX first (your saves are backed up) and then install this one.

ALPHA software. Please send logs if anything breaks.
