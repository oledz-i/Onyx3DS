**ONYX v2.0: games boot on Xbox.**

This is the first release where 3DS games boot and play on an Xbox Series X|S in Dev Mode. New Super Mario Bros. 2 has been tested in-game on a Series S.

### Install
Download **two files** below: `ONYX3DS-v2.0.msix` and the dependency `.appx`. In the Xbox Device Portal choose **Add**, pick the `.msix`, add the dependency, and install. Then set ONYX's **App type to Game** in Dev Home. Full guide: [docs/INSTALL.md](https://github.com/oledz-i/Onyx3DS/blob/main/docs/INSTALL.md).

### What's new
- **Games boot.** CPU JIT (dynarmic) runs under Xbox's W^X rules, Azahar's folders are created correctly inside the app sandbox, and the software renderer is the default.
- **Faster software rendering.** Rasterizer work is batched instead of being queued per scanline, the frame blit is about 4x faster, and frames are no longer copied to an off-screen D3D12 surface.
- **No more Xbox mouse cursor.** The controller drives the menus and the game directly.
- **Smoother menus.** Tile art is cached and icons load off the UI thread; settings and play time are saved in the background.
- **Crash protection.** Emulator errors stop the game with an explanation instead of closing the app. A crash in the CPU JIT or the hardware renderer switches that setting to its safe option automatically.
- **Better logs.** `onyx.log` records crashes (module + offset), memory use, renderer details and driver messages.

### Known issues
- **Speed.** Software rendering is CPU-bound. Light 2D scenes run best; expect slowdown and some audio crackle in busy scenes.
- **Hardware renderer (Vulkan via Dozen) is experimental** and currently loses the GPU device on Series S. Leave *Settings → Renderer* on *Software*.
- Report problems with `onyx.log` attached: [new issue](https://github.com/oledz-i/Onyx3DS/issues/new/choose).

`ONYX3DS-v2.0.map` is only for decoding crash logs; you don't need it to install.
