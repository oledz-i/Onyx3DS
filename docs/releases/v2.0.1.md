**ONYX v2.0.1: fixes the "ONYX 3DS hit a problem" screen when a game starts.**

v2.0 turned Xbox mouse mode off a second time when a game started, which Xbox doesn't allow while the app is running. The error replaced the screen (the game kept running behind it) and also stopped the faster v2.0 picture path from switching on.

- Mouse mode is turned off once at app start-up only; the game screen hides the cursor safely.
- Game start now shows the picture first, and the optional extras (load state on launch, cheats, remembering the last game) can no longer take the screen down if one of them fails.
- UI errors are logged with their error code.

Install: download `ONYX3DS-v2.0.1.msix` and the dependency `.appx` below, and install them the same way as before. Settings and saves are kept.
