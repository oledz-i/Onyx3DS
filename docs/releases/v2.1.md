**ONYX v2.1: the speed update.**

The software renderer was rebuilt around the Xbox's CPU cores, a frame skip option makes slow scenes playable, and the hardware renderer now explains itself when it fails.

### Install
Download **two files** below: `ONYX3DS-v2.1.msix` and the dependency `.appx`. In the Xbox Device Portal choose **Add**, pick the `.msix`, add the dependency, and install. Keep ONYX's **App type set to Game** in Dev Home. Full guide: [docs/INSTALL.md](https://github.com/oledz-i/Onyx3DS/blob/main/docs/INSTALL.md).

### What's new
- **Much faster software rendering.**
  - Each draw call is split into screen bands that every available core draws at once, with the emulation thread helping. Before, most triangles were drawn one at a time on a single thread while the other cores waited.
  - The number of drawing threads matches the cores the Xbox actually gives the app.
  - Screen transfers and the final screen conversion now also run on all cores.
  - Per-pixel work is cheaper:
    - Unused texture coordinates and pass-through color stages are skipped.
    - Each triangle row's covered span is computed directly.
    - Same-format screen copies are plain memory copies.
  - On a Series S, the New Super Mario Bros. 2 menu went from about 2 fps (v2.0.1) to about 5 fps in testing, before the last round of changes.
- **Frame skip** (Settings → Frame skip, the in-game quick menu, or per game). It draws every 2nd, 3rd or 4th frame while the game itself keeps full speed, so slow menus and busy scenes become playable. Some games may flicker.
- **Hardware renderer diagnostics.**
  - Before a game starts, ONYX runs a short step-by-step Vulkan self-test and logs exactly which GPU operation fails.
  - The Dozen driver now writes its own error messages and Direct3D error codes into `onyx.log`.
  - Dozen no longer submits command buffers that failed to record. Running one is an invalid Direct3D call, which removes the whole GPU device.
- **Better performance logs.** `onyx.log` lists up to 200 hot spots per thread every 10 seconds, so slow games can be tuned from a single log.

### Known issues
- The **hardware renderer** may still fail on Series S. If it does, ONYX switches back to software automatically. Please attach `onyx.log` to an issue: the self-test lines show exactly what failed.
- Heavy 3D games remain slow on the software renderer. Frame skip and a lower CPU clock can help.

`ONYX3DS-v2.1.map` is only for decoding logs; you don't need it to install.
