**ONYX v3.0.3: all work from DanP's Azahar has been removed, effective immediately.**

At the author's request, everything in ONYX that came from DanP's Azahar has been removed. That includes the bundled OpenGL runtime and the OpenGL fixes patch, along with the credits for them. The earlier v3.0.0, v3.0.1 and v3.0.2 releases contained that work and have been taken down.

What this means for you
- **OpenGL is gone for now.** Hardware rendering is Vulkan only until ONYX has its own OpenGL support. Anyone who had OpenGL selected is moved to Vulkan automatically. Software rendering is unchanged.
- **Everything else from v3.0.1 and v3.0.2 is kept:** the on-screen keyboard (with the controller fixes from v3.0.2), NES improvements and patch support, and the Vulkan hold-the-last-picture change.
- Install over your current copy; your saves and settings carry over.

ALPHA software. Please send logs if anything breaks.
