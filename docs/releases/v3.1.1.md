**OnyxEMU v3.1.1 (ONYX): a new name and a new look. The game you pick fills the background, optional box art, critics' scores, six new ambient soundtracks and a smoother way through your library.**

What's new
- **ONYX is now OnyxEMU.** New name, new logo (a cut gem instead of the two screens), new splash screen and tiles. On the Xbox home screen and in Dev Home the app now shows as "OnyxEMU". It is the same app underneath, so your saves, settings and library carry over and the new version installs over the old one.
- **The game fills the background.** Highlight a game and a faded picture of it (a gameplay screenshot, downloaded once) fades in behind the menu and drifts slowly. The old banner and screenshot slideshow are gone. Turn it off under Settings > Interface > "Game picture as the background".
- **Box art (optional).** Settings > Interface > "Box art" shows each game's box art instead of its banner picture, in the crossbar rows, the channel grid and a large cover beside the game's details. Box art is downloaded once per game from the libretro thumbnail project, for most US and European 3DS releases (and GBA and NES). Box art belongs to Nintendo.
- **More about each game.** The details panel now shows the critics' average as stars with the score, genre tags, the description, and the release, developer and publisher.
- **Smoother selection.** The list glides to the game you land on, the highlighted row slides toward the details, the details slide in, and opening a game fades the menu out over its picture.
- **Six new soundtracks.** Every theme has its own calm ambient track, written for ONYX; none share music any more. (Your own music in the Music folder still works.)
- **Graphics fixes.** (a) Vulkan: images are now freed only after the GPU has finished with them. Before, a freed picture's memory could be handed to a new one while the GPU was still drawing to the old one, which fits the static on Smash models and the black characters and flickering sky in Mario Kart 7. (b) OpenGL: the bottom screen is no longer drawn with constant-alpha blending when fully opaque, which Mesa's Direct3D 12 driver handled wrongly and left the screen black. (c) the vertex cache is off by default, see below.
- **Mario Kart 7 flicker fixed by turning the vertex cache off.** A log from Mario Kart 7 with the cache off shows a steady 60 fps and no black characters or flickering sky, so the cache was the cause. It is now off by default (Settings > "Vertex cache (experimental)"). If you turned it on in a test build, check that setting.
- **Box art for many more games.** Box art matching was too strict, so games such as Ocarina of Time 3D, Super Smash Bros. for 3DS and Super Mario Maker got none. Names are now matched loosely (word order, "The", "for Nintendo 3DS", subtitles), every region is accepted (USA, Europe, Japan and others, including Japan-only games), and when a game still has no match, its cartridge ID is used to ask GameTDB for the box. Games that found nothing before are tried again once. Not yet confirmed on a console: please tell me which games still show no box.
- **Credits** now list the thumbnail project and Wikipedia, and say that box art is Nintendo's.

Things to know
- Graphics fixes in this update are best guesses from the logs and code, not confirmed on a console. Please test and send logs: (1) Smash static/noise and Mario Kart 7 black characters or flickering sky; (2) the black OpenGL bottom screen.
- The background picture, scores and box art need an internet connection the first time. Everything is cached afterwards, and games the sources don't know are remembered so ONYX doesn't keep asking.
- Scores come from Wikipedia's review boxes, so some games have none.
- Not every game has a screenshot or box art online; those fall back to the banner or the card.
- Apart from the switch above, this update changes the menu only. Emulation speed is unchanged.

ALPHA software. Please send logs if anything breaks.
