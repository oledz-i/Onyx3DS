**OnyxEMU v3.1.1: ONYX gets a new name and logo, a redesigned home screen (the game fills the background, box art, critics' scores, six new soundtracks), a steady 60 fps in Mario Kart 7, and a working OpenGL bottom screen.**

What's new
- **ONYX is now OnyxEMU.** New name, a new logo (a cut gem), a new splash screen and new tiles. On the Xbox home screen and in Dev Home the app now shows as "OnyxEMU". It is the same app underneath: your saves, settings and library carry over, and this version installs over the old one. (The project page has moved to the OnyxEMU repository; old links still redirect.)
- **The game fills the background.** Highlight a game and a faded picture of it (a gameplay screenshot, downloaded once) fades in behind the menu and drifts slowly. The old banner and screenshot slideshow are gone. Turn it off under Settings > Interface > "Game picture as the background".
- **Box art (optional).** Settings > Interface > "Box art" shows each game's box art in the crossbar rows, the channel grid and a large cover beside the game's details, instead of the banner picture. It is downloaded once per game, for NTSC and PAL releases alike. Box art belongs to Nintendo.
- **Box art for many more games.** Matching used to need an almost exact title, so Ocarina of Time 3D, Super Smash Bros. for 3DS and Super Mario Maker got none. Titles are now matched by their words ("The", word order, "for Nintendo 3DS" and subtitles no longer matter), every region counts (USA, Europe, Japan and others, so Japan-only games such as the Ace Attorney collections can match), and when a game still has no match its cartridge ID is used to ask GameTDB for the box. Games that found nothing before are tried again once. GBA and NES box art already worked.
- **More about each game.** The details panel shows the critics' average as stars with the score, genre tags, the description, and the release date, developer and publisher.
- **Smoother selection.** The list glides to the game you land on, the highlighted row slides toward the details, the details slide in, and opening a game fades the menu out over its picture.
- **Six new soundtracks.** Every theme has its own calm ambient track, written for OnyxEMU; none share music any more. Your own music in the Music folder still works.
- **Mario Kart 7 runs a steady 60 fps with no black characters or flickering sky.** The cause was the vertex cache added in 3.1.0, so it is now off by default (Settings > "Vertex cache (experimental)"). If you turned it on in a test build, check that setting.
- **OpenGL bottom screen fixed.** The bottom screen was black on OpenGL. It is no longer drawn with constant-alpha blending when fully opaque, which Mesa's Direct3D 12 driver handled wrongly. Confirmed on a console.
- **Vulkan graphics.** Images are now freed only after the GPU has finished with them, which stops a freed picture's memory being reused while it was still being drawn to.
- **Credits** now list the libretro thumbnail project, GameTDB and Wikipedia, and say that box art is Nintendo's.

Things to know
- **Not recommended for now: Super Smash Bros. for 3DS and the Pokemon games.** Smash still shows heavy graphical glitches on both Vulkan and OpenGL: static and noise on models, and many assets missing, bad enough that it is not playable (OpenGL loads a few more assets than Vulkan). The Pokemon games have not been tested yet, and since they are 3D-heavy like Smash I would not expect them to be good. This is being worked on.
- The Mario Kart 7 fix is the vertex cache being off. The cache itself still has a bug that I haven't found, which is why it is optional and experimental.
- Box art from GameTDB (used only when the thumbnail project has no match) has not been tested on a console yet. Tell me which games still show no box.
- The background picture, scores and box art need an internet connection the first time. Everything is cached afterwards, and games the sources don't know are remembered so OnyxEMU doesn't keep asking.
- Scores come from Wikipedia's review boxes, so some games have none. Not every game has a screenshot or box art online; those fall back to the banner or the card.
- The new menu music and animations have had little testing on a console.

ALPHA software. Please send logs if anything breaks.
